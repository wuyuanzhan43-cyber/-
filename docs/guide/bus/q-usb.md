answer: |
  **USB 主机-设备**：主机（Host）主导，设备（Device）响应；通过**端点（Endpoint）**与主机交换数据。
  **端点/传输类型**：
  - **端点**：`IN/OUT`，有**地址**；类型：**控制/批量/中断/等时**。
  - **控制传输**：枚举/配置（设备请求）。
  - **批量传输**：大块数据（存储/U盘），出错重传，无延迟保证。
  - **中断传输**：少量、周期（键盘/鼠标/HID），有延迟上限。
  - **等时传输**：实时（音频/视频），无重传，保证带宽与间隔。
  **枚举流程**（设备接入后）：
  1. 上电/复位 → 检测到设备（D+/D- 电平）。
  2. **地址分配**（Set Address，默认地址 0）。
  3. **读描述符**（设备、配置、接口、端点）→ 了解设备能力。
  4. **配置**（Set Configuration）→ 设备进入就绪，主机按配置通信。
  **描述符**：设备/配置/接口/端点描述符，描述 VID/PID、接口类型、端点属性和带宽。
  **接口类**：HID（键鼠）、CDC（串口/虚拟串口）、MSC（存储）、Audio 等。**速度**：低速1.5M/全速12M/高速480M/超速5G。
why: |
  USB 是通用外设总线，**主机-设备、端点、传输类型、描述符**是核心。理解 **枚举**（设备怎么被识别/配置）与**端点/传输类型**（控制/批量/中断/等时各适合什么），才能写 **USB 设备/主机驱动**，做**U 盘(MSC)、虚拟串口(CDC)、键盘(HID)、音视频(等时)**。
  嵌入式里常用 **USB 设备（做 U 盘/CDC 串口/读卡器）** 或 **USB 主机（读 U 盘/连鼠标）**。

## 深读

### 端点与传输类型

| 类型 | 用途 | 特点 |
|---|---|---|
| 控制 | 枚举/设备请求 | 双向、可靠 |
| 批量 | 大块数据（U盘） | 可靠、无带宽保证 |
| 中断 | HID/键鼠（小量周期） | 有延迟上限 |
| 等时 | 音频/视频 | 实时、无重传、保带宽 |

- 端点用 `IN`（设备→主机）/`OUT`（主机→设备）+ 端点号标识。

### 枚举流程

```
设备上电 → 复位 → GetDescriptor(设备) → SetAddress → GetDescriptor(配置/接口/端点) → SetConfiguration → 通信
```

- 设备通过描述符告诉主机“我是谁、有什么端点、怎么用”。
- **SetConfiguration** 后设备进入可用的配置状态。

### 描述符

- **设备描述符**：VID/PID、设备类、版本。
- **配置描述符**：接口/端点总数、供电/电流。
- **接口描述符**：接口类（HID/CDC/MSC）、端点。
- **端点描述符**：端点地址、类型、最大包、间隔（中断/等时）。

### 常见设备类

- **HID**：键鼠、手柄（中断传输）。
- **CDC**：虚拟串口（Com 口，批量/中断）。
- **MSC**：U 盘/读卡器（批量）。
- **Audio/Video**：等时。

### 常见追问

- 枚举是干什么？——主机识别并配置设备（地址/描述符/配置）。
- 四种传输类型区别？——控制(枚举)、批量(大块可靠)、中断(小量周期)、等时(实时无重传)。
- 端点 IN/OUT 什么意思？——主机视角：IN=设备→主机，OUT=主机→设备。
- 什么是 CDC/HID/MSC？——设备接口类：串口/键盘/存储。

> 📌 一句话记忆：**USB=主机-设备+端点(控制/批量/中断/等时)+描述符；枚举=地址分配+读描述符+配置；HID/CDC/MSC/Audio 是常见设备类。**

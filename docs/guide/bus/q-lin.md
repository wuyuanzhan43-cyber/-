answer: |
  **LIN（Local Interconnect Network）**：汽车**低成本低速**串行总线，用**单线（12V）**，**主从**（1 主 + 多从，最多约 16 节点），速率约 **20kbps**（低速），基于 **UART（SCI）**，用于**车身**（车窗、雨刷、车灯、空调、后视镜等）。
  **帧结构**：`同步断(Synch Break) | 同步场(0x55) | 标识符(PID：帧ID+校验) | 数据(0~8B) | 校验和`.
  - **主节点**发布**帧头**（同步断/同步场/标识符），从节点应答数据（或主节点发送数据给从）。
  - **调度表**：主节点按**调度表**周期发送帧头，决定通信时序（确定性）。
  - **标识符**：对应报文/帧；与 CAN 类似用于寻址，但 LIN 由**主节点主导**。
  - **低成本**：只需一根线（继电器/开关电平），配合 UART，常用于**低速车身**。
  **对比 CAN**：CAN 高速/多主/可靠用于动力/底盘；**LIN 低速/主从/便宜**用于车身舒适性（与 CAN 互补）。
why: |
  汽车里 **CAN 用于高速/关键（动力、刹车）**，而**大量低成本车身节点（车窗、灯、雨刷）**用**更便宜的单线 LIN**（配主从/调度表，确定性、低速率即可）。用一个**主节点 + 多个从节点**，基于 UART 实现，成本极低。
  理解 LIN 的**主从结构、帧（同步断/标识符/数据）、调度表**，才能做车身电子（车窗/灯控等）与 CAN/LIN 混合网络。

## 深读

### LIN 特点

| 项 | 说明 |
|---|---|
| 物理 | 单线（12V），低成本 |
| 拓扑 | 主从（1主 + 多从，≤16） |
| 速率 | ~20kbps（低速） |
| 底层 | 基于 UART（SCI） |
| 用途 | 车身（车窗/灯/雨刷/空调） |
| 对比 | 与 CAN 互补（CAN 高速关键，LIN 低速便宜） |

### 帧结构

```
同步断 | 同步场(0x55) | 标识符PID | 数据(0~8B) | 校验和
```

- **同步断**：通知从机“帧开始”（长的低电平）。
- **同步场**：0x55，从机据此**测量波特率**（从机可自适应）。
- **标识符**：帧 ID + 校验（PID），对应报文/从机。
- **数据/校验**：有效载荷 + 校验和。

### 主从与调度表

- **主节点**：发布**帧头**（同步断/同步场/标识符）。
- **从节点**：根据标识符决定**应答**（发数据）还是**接收**（主发数据）。
- **调度表**：主节点按预定义顺序/周期发帧头，决定通信时序 → **确定性**（适合实时/周期采样）。

### 与 CAN 对比

- **CAN**：高速（经典 CAN 最高 **1Mbps**，**CAN FD** 可更高）、多主、差分、可靠，用于**动力/底盘/安全**。
- **LIN**：低速（20k）、主从、单线、便宜，用于**车身舒适**。
- 常**混用**：CAN 主干 + LIN 子网（低成本车身节点）。

### 常见追问

- LIN 用什么底层？——UART/SCI；单线、主从。
- LIN 快吗？——~20kbps，低速，适合车身低成本。
- 为什么用调度表？——主节点按周期发帧头，时序确定（适合周期采样/确定性）。
- LIN 和 CAN 关系？——互补：CAN 高速关键，LIN 低速便宜车身。

> 📌 一句话记忆：**LIN=汽车单线主从低速总线(20k,基于UART,车身用)；帧=同步断+同步场+标识符+数据+校验；主节点调度表定时序；与CAN互补。**

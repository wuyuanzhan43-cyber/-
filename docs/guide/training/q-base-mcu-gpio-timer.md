answer: |
  **GPIO**：引脚可配**输入/输出/复用/模拟**。关键参数：
  - **输入模式**：浮空/上拉/下拉/模拟。**上拉=默认高、下拉=默认低**，给**悬空引脚确定电平**、防误触发。
  - **输出模式**：**推挽**（可拉高可拉低、驱动强，用于 LED/输出）、**开漏**（只能拉低、高靠外部上拉，支持**线与**，用于 I2C 等多设备共享）。
  - **复用**：配成 UART/SPI/I2C/PWM/ADC 等外设功能。

  **定时器**：按**时钟分频计数**，计到**自动重装载（ARR）**则溢出/更新。可做：**定时中断**（周期任务/tick）、**输入捕获**（测频率/脉宽）、**输出比较**、**PWM**。
  **PWM**：`周期 = (ARR+1)*(PSC+1)/fclk`，**占空比 = CCR/ARR**。用于**调速（电机）、调光（LED）、控制舵机、模拟输出**。调节占空比 = 调平均电平/功率。

  **ADC**：把模拟电压转数字。**分辨率**（如 12 位=0~4095）决定精度；**采样率 ≥ 2×信号最高频**（奈奎斯特，防混叠）；**参考电压**决定量程（`值 = Vin/Vref × (2^N-1)`）。采样后常**滤波**：随机噪声用**均值/低通**，脉冲用**中值**，先防抖。
why: |
  GPIO/定时器/PWM/ADC 是**嵌入式最基础的外设**，几乎任何 MCU 项目都会用到。能说清 **GPIO 上下拉（防浮空）、推挽/开漏（I2C 用开漏）、定时器公式、PWM 周期/占空比、ADC 分辨率/采样率/滤波**，就是单片机底子——也是你外设驱动、传感器采集、PWM 控制的基础。

## 深读

### GPIO 上拉/下拉
- **上拉**=默认高（按键默认高、I2C 空闲高）；**下拉**=默认低。
- **推挽**：强驱动，单独驱动；**开漏**：只拉低+外部上拉，**线与**（I2C）。

### 定时器 / PWM
```
f = fclk / ((PSC+1)*(ARR+1))    // PWM 频率
占空比 = CCR / ARR
```

### ADC
```
值 = (Vin / Vref) * (2^N - 1)    // 12 位 → 0~4095
采样率 ≥ 2 × fmax(防混叠)；采样后均值/中值/低通滤波
```

### 常见追问
- 为什么按键要上拉/下拉？——防浮空误触发，给定默认电平。
- 为什么 I2C 用开漏+上拉？——多设备线与，避免短路。
- 定时器周期怎么算？——(ARR+1)*(PSC+1)/fclk。
- ADC 采样率不够会怎样？——混叠，读数错误。

> 📌 一句话：**上拉=默认高、下拉=默认低（防浮空）；推挽强驱动、开漏只拉低+上拉（I2C 线与）；定时器/PWM 看 ARR+PSC+CCR；ADC 看分辨率+采样率+参考电压，采样后滤波。**

answer: |
  **进程（process）**：**资源分配的最小单元**，有**独立地址空间**（有自己的代码/数据/堆/栈），进程间**不共享内存**，通信要 IPC（管道/信号等）。开销大（创建/切换要换地址空间、页表）。
  **线程（thread）**：**CPU 调度的基本单位**，**共享所属进程的地址空间与资源**（堆、全局变量），**各自有独立栈 + 寄存器上下文**；创建/切换开销小，但**共享变量要同步**（锁/原子）。
  **任务（task）**：RTOS 里**同等于线程**概念，是**调度的基本单位**，每个任务**独立栈 + 优先级 + 状态**；裸机/RTOS 里的「任务」和移动端/桌面里的「线程」是**同类**。

  **区别**：进程 = 独立地址空间（安全、隔离强、开销大）；线程/任务 = 共享地址空间（高效、但需同步）。嵌入式 RTOS 用**任务**（=线程），共享一块内存、靠信号量/队列同步。

  **调度**：决定**哪个任务此刻运行**。常见：**优先级抢占**（高优先级就绪立即抢占）、**时间片轮转**（同优先级轮流）、**协作式**（主动让出）。RTOS 取**最高优先级的就绪任务**运行。
why: |
  这是嵌入式 OS 的**第一性概念**：**进程 vs 线程/任务**（资源单元 vs 调度单元）、**独立地址空间 vs 共享 + 同步**、以及**调度是选最高优先级就绪任务**。能说清这些，才谈得上 RTOS 的同步、优先级反转、上下文切换。

## 深读

### 进程 vs 线程对比
| | 进程 | 线程/任务 |
|---|---|---|
| 粒度 | 资源分配单元 | 调度单元 |
| 地址空间 | **独立** | **共享**(堆/全局) |
| 栈 | 独立 | **各自独立栈** |
| 同步 | IPC(管道/信号) | 锁/原子/队列 |
| 开销 | 大 | 小 |

### 嵌入式任务三要素
- **独立栈**、**优先级**、**状态**（运行/就绪/阻塞/挂起）。
- RTOS 调度 = 取**最高优先级就绪任务**运行；高优就绪即抢占。

### 常见追问
- 进程和线程区别？——进程=独立地址空间；线程=共享地址空间的调度单元，各有独立栈。
- 为什么线程切换快？——不用换地址空间/页表，只换寄存器上下文。
- RTOS 调度策略？——优先级抢占 + 时间片轮转。

> 📌 一句话：**进程=资源分配单元(独立地址空间)；线程/任务=调度单元(共享地址空间、各独立栈)；RTOS 调度=选最高优先级就绪任务运行。**

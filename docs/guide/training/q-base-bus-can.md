answer: |
  **CAN（控制器局域网）**：**多主、差分、基于报文标识符仲裁**的串行广播总线，广泛用于**汽车、工业**（要求高可靠、实时、多节点共享）。

  **要点**：
  - **物理层**：**双绞线 CAN_H/CAN_L，差分信号**抗干扰；总线两端各接一个 **120Ω 终端电阻**（匹配阻抗、防反射）。
  - **多主 + 仲裁**：任意节点都可发，冲突靠**标识符逐位仲裁**（**标识符数值越小优先级越高**，0 为显性）；发隐性却被显性覆盖的节点**退避**。
  - **帧结构**：标准帧 **11 位** ID、扩展帧 **29 位**；含 SOF/仲裁域/控制域/数据域(0~8B)/CRC/ACK/EOF。
  - **可靠性**：CRC、错误帧、自动重发、错误检测与故障隔离（错误计数、总线关闭）。

  **仲裁原理**：总线两态——**显性（dominant，0）** 覆盖 **隐性（recessive，1）**。多个节点同时发，从 ID 最高位逐位比较；发隐性却读到显性的节点判**仲裁失败**退避，胜者继续。**ID 越小 → 更早出现 0 → 越易赢 → 优先级越高**。

  **速率与线长**：**线越长速率越低**（传播延迟限制，1Mbps 常在数十米内）；常见 125k~1M。

## 深读

### 为什么 ID 越小优先级越高
- 多个节点同时发，从最高位逐位比较；**显性(0) 覆盖 隐性(1)**。
- ID 数值小 → 位串更早出现 0 → 赢仲裁 → 优先级高。

### 帧（简化）
```
[SOF][仲裁域(ID+RTR)][控制域][数据域(0~8B)][CRC][ACK][EOF]
```
- 仲裁域 = 标识符(既是寻址又是优先级) + 数据/远程帧标志。

### 常见追问
- CAN 是多主还是一主多从？——**多主**，冲突靠仲裁。
- 终端电阻多大、为什么？——两端 120Ω，匹配总线阻抗、防反射。
- 为什么线长和速率成反比？——传播延迟限制位时间。
- AR 错误/总线关闭？——错误计数触发，bus-off 需恢复序列/复位。

> 📌 一句话：**CAN=多主/差分/按标识符逐位仲裁(ID 小优先级高)/带检错自动重发；两端 120Ω 终端电阻，速率与线长成反比。**

answer: |
  **函数指针**：**指向函数的指针**，存的是**函数地址**。定义与使用：
  ```c
  int (*fp)(int, int);   // 指向 int(int,int) 型函数
  fp = add;              // 指向函数 add
  int r = fp(2, 3);      // 调用
  ```
  语法上`(*fp)` 是指针、后面 `(int,int)` 是参数类型、前面 `int` 是返回类型。

  **回调（callback）**：把**函数当作参数**传给另一个函数，运行期由**被调方**去调用——常用于**事件通知、异步完成、注册处理函数**（如注册中断处理、协议解析回调、比较函数给 `qsort`）。

  **为什么用（嵌入式重点）**：
  - **解耦/多态**：上层只依赖**接口**（函数指针），不知道具体实现——**结构体 + 函数指针 = C 里的面向对象/虚表**（你框架的驱动模型、OSAL 就用这个）。
  - **表驱动**：用**函数指针数组**做**命令/状态分派**（如状态机转移表、命令表），比 if-else 清晰、易扩展。
  - **可替换/可测**：换实现只换注册的函数，上层不动。

  **注意**：回调要**短、可重入、不阻塞**（尤其中断里的回调）；指针类型要匹配（参数/返回类型一致）。

## 深读

### 结构体 + 函数指针 = 接口/多态（你的驱动模型）
```c
typedef struct { int (*open)(void*); int (*read)(void*, char*, int); } DeviceOps;
// 上层只调 ops->read(...)，不知道具体是 UART 还是 SPI → 多态
```

### 表驱动状态机/命令表
```c
typedef int (*handler)(int cmd, void* arg);
handler table[N];  // cmd 作下标，直接调 table[cmd](cmd, arg)
```

### 常见追问
- 函数指针怎么定义？——`返回类型 (*变量)(参数类型)`。
- 回调是什么、干嘛用？——函数当参数，运行期被调方调用；用于事件/异步/解耦/多态。
- 结构体和函数指针能模拟什么？——接口/虚表/多态（面向对象）。
- 中断回调要注意什么？——简短、可重入、不阻塞。

> 📌 一句话：**函数指针=指向函数的指针；回调=把函数当参数实现解耦/多态；结构体+函数指针=C 的面向对象接口；函数指针数组可做表驱动状态机。**

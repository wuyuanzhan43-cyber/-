  **Q：你说「识别准确率通过板级验证」，具体是多少？怎么测的？每帧推理耗时和内存占用是多少？**

  **A（你怎么答）：**（一定要**报真实数字**，并说清怎么测的）
  - **准确率**：我在板子上用真实传感器采集的**测试集**（比如 **X 组手势**、覆盖 **150 类**）跑，**正确识别数 / 总数** = 准确率 **X%**。测试集**不含训练数据**，避免过拟合虚高；说明误识率、有没有类别混淆。
  - **单帧推理耗时**：用**定时器/毫秒计数**测「300 帧滑窗 → 推理 → 出类别」这一段的耗时，实测 **X ms**；100Hz 采样下，每帧采集 **10ms**，推理要在**另一核**并行做，保证**不阻塞采集**。
  - **内存**：tensor arena 峰值 **X KB**（用 TFLM arena 峰值统计/工具测量），放**片内 RAM**；整机 RAM 占用 **X KB**（`xPortGetFreeHeapSize` / 内存映射查看）。
  - **CPU 占用**：推理核在 100Hz 下 CPU 占用 **X%**，说明**还有余量**、实时性可控。
why: |
  这题是「真实 vs 嘴上说说」的**试金石**。面试官要的不是名词，而是**数字 + 测量方法**。**报不出数字、或说不出怎么测的，整段「板级验证」就塌了**。所以务必把你板级实测的真实值填进去，并想清楚准确率用**什么测试集**、耗时用**什么方法**、内存用**什么接口**测。

## 深读

### 一套「能报的数字」模板（把 X 换成真实值）
| 指标 | 怎么测 | 报多少 |
|---|---|---|
| 识别准确率 | 板端真实数据集（不含训练数据）跑 | X% |
| 单帧推理耗时 | 定时器测滑窗→推理→输出 | X ms |
| 采集节拍 | 100Hz = 10ms/帧，是否稳定（有无抖动） | 稳定/抖动 X ms |
| tensor arena | TFLM 峰值统计 | X KB |
| 整机 RAM | `xPortGetFreeHeapSize` / 内存映射 | X KB |
| CPU 占用 | 推理核在 100Hz 下 | X% |

### 怎么让准确率「站得住」
- **测试集独立**：不用训练数据，最好留出**未见过的真实手势**。
- **说明误识来源**：哪几类容易混（如相近手势），你是怎么处理的（更多帧/特征）。
- **识别门槛**：logits 最大得分低时**丢弃/让用户重做**，别硬猜（这是工程化细节，说出来加分）。

### 把八股接回项目
答完加一句：「**我测这些是为了证明不是实验室理想值，而是真的能在板子上稳定 100Hz 跑。**」

answer: |
  **指针 vs 数组**
  - **数组名**：多数场景退化为**首元素地址**（`&arr` 除外），但数组是**地址常量**，不能自增；指针是**变量**，可自增/改指向。
  - `sizeof`：`sizeof(arr)` = 整个数组字节；`sizeof(ptr)` = 指针本身大小（如 4/8 字节）。
  - **是地址**：数组名在表达式里多作为首地址传给指针。

  **指针数组 vs 数组指针（容易混）**
  - **指针数组 `int *a[10]`**：先看 `a[10]` 是**数组**，每个元素是 `int*` 指针 → **10 个指针**。
  - **数组指针 `int (*p)[10]`**：先看 `(*p)` 是**指针**，指向 `int[10]` 数组 → **指向一维数组的指针**（常用来遍历二维数组）。

  **区分口诀**：`[]` 优先级高于 `*`，所以 `int *a[10]` 先结合 `[]`（是数组）；`int (*p)[10]` 用括号强制 `*p` 先结合（是指针）。

  **解引用**：`*a[0]` = 取第一个指针指向的值；`(*p)[0]` = 取数组第一个元素。

  「指针/数组/指针数组/数组指针」是**嵌入式 C 面试必考**，考的其实是**运算符优先级 + 指针本质**。能快速分清 `int *a[10]` 和 `int (*p)[10]`，并能说出**数组名退化为地址但不可自增、sizeof 差异**，就是 C 底子过关。

## 深读

```c
int a[10];        // a 是数组名，表达式里退化为 &a[0]；a 不能自增
int *p = a;       // p 是指针，可 p++

int *arr[10];     // 指针数组：10 个 int* 元素
int (*ptr)[10];   // 数组指针：指向 int[10] 的指针

sizeof(a)     // 40 (10*int)
sizeof(p)     // 4 或 8（指针大小）
```

### 常见追问
- `int *a[10]` 和 `int (*a)[10]` 区别？——前者是指针数组(10 个指针)，后者是数组指针(指向长 10 的数组)。
- 数组名和指针一样吗？——数组名是**地址常量**，不能赋值/自增；指针是变量。多数表达式里数组名退化为首地址。
- `sizeof(arr)` 和 `sizeof(&arr[0])`？——前者是整个数组字节，后者是指针大小。

> 📌 一句话：**数组名退化为首地址但不可改；指针可改；`[]` 优先于 `*` → `int *a[10]`=指针数组、`int (*p)[10]`=数组指针。**

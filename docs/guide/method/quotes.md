# 面试金句速记

> 把每章最值得“背下来”的一句话收在这里，方便临场脱口而出。真正的理解还是看各题深读。

## C 语言与内存

- **volatile = “别把它当普通变量省着用，去真实源头读”**；但它治不了原子性与乱序。
- **`const` 在 `*` 左→锁值，在 `*` 右→锁针**；函数形参多用 `const int *` 表达“只读”。
- **栈 = 自动、LIFO、有限、快（溢出）；堆 = 手动、灵活、有泄漏/碎片**。
- **内存对齐是为了“一次取到/不越界”，`sizeof` 看“最宽成员对齐”，重排成员能省内存。**
- **位域省内存但布局不可移植**：同平台内部可用，**对外协议用定宽整型 + packed + 移位 + 字节序转换 + 静态断言**。
- **`int *p[10]`=指针数组（元素是指针）；`int (*p)[10]`=数组指针（指向数组）。**
- **C 里“无符号优先+整型提升”把负数变巨大正数**；混算、unsigned 减法、sizeof 下溢都要显式强转。

## 操作系统与并发

- **进程=资源容器（隔离贵）；线程=执行流（轻量但要同步）**；RTOS 用“任务”近似线程。
- **用户态受限，靠“系统调用/中断/异常”陷入内核态代办敏感操作**；陷入贵，所以少调用、批量、mmap/io_uring。
- **死锁 = “互持不可循”（互斥/持有并等待/不可剥夺/循环等待），破坏任意一个就能防；最实用是统一加锁顺序。**
- **Mutex = “只准一人进的门”（有主、带继承）；Semaphore = “计数/发信号的牌”（无主、可计数）。**
- **自旋锁=忙等占 CPU、禁睡眠，适合原子/中断上下文与极短临界区；睡眠锁=让出CPU、可调度。**
- **中断里“极短、不阻塞、可重入、不能调度”；重活丢到底半部/任务/队列去做。**
- **实时性=确定性（每次都在时限内），看 WCRT/中断延迟/抖动；用优先级抢占+短临界区+非阻塞。**

## ARM 与中断

- **向量表=异常/中断的“入口地图”**；上电走复位向量→特权模式→建栈→拷 data→清 bss→进 C。
- **复位读向量表前两项：第 1 个 = 初始 MSP（栈顶），第 2 个 = 复位地址 PC（从哪跑）**；错了上电即死。
- **NVIC(Cortex-M)=向量化+优先级分组+嵌套；GIC(Cortex-A)=分发到核+SPI/PPI/SGI+核间中断。**
- **MMU=地址转换+保护(页, Cortex-A/OS)；MPU=仅区域保护(Cortex-M/RTOS, 无转换)。**

## 总线与通信

- **I2C=2 线省线、靠地址挂多从（半双工、慢）；SPI=4 线、靠片选挂多从（全双工、快）；UART=无钟、点对点。**
- **开漏 + 上拉 = I2C 能实现多主仲裁与从机应答的物理基石；不接上拉总线就回不到高电平，必然失效。**
- **知道 Repeated START，说明你理解 I2C 流程设计的动机——它保证“写寄存器→读数据”的原子性。**
- **读 I2C 最后一个字节必须由主机回 NACK**（回了 ACK 从机会继续驱动 SDA，总线异常）。
- **SPI“发送必伴随接收”，读 FLASH 要先发 0xFF（只为产生时钟，数据在 MISO 同步收回）。**
- **乱码先查“波特率(时钟/分频)+帧格式”，再查“TX/RX 交叉+电平”；丢字节是“发送比接收快→缓冲溢出”，用中断/DMA+环形缓冲+流控。**
- **CAN 逐位仲裁，ID 数值越小优先级越高；CAN 是数据链路层的成功确认，与应用层是否处理无关。**
- **RS485 差分、半双工、多点、需方向控制 + 120Ω 终端；Modbus 主从 + 功能码 + CRC16。**

## Linux 与 MCU

- **DMA 绕 cache 直访内存会不一致：CPU→设备要 flush(写回)，设备→CPU 要 invalidate(失效)。**
- **设备树=外置的“硬件清单/连线图”，compatible 匹配把 DT 设备“交给”驱动；一内核多板卡。**
- **上拉=默认高、下拉=默认低（给悬空引脚确定电平）；推挽强驱动(LED)，开漏只拉低+外部上拉(I2C 线与)。**
- **STM32 时钟树=时钟源(HSE/HSI)→PLL→SYSCLK→AHB/APB 分频→外设时钟(需单独使能)；配错则外设不动/计时不准。**
- **分不清 A/B：A 是“进程地址空间隔离”，B 是“DMA 直访内存不走 cache”，二者都靠内核接口/一致化处理。**

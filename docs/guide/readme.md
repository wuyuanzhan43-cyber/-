# 嵌入式八股面试手册

> 一本「**题卡 + 标准答案 + 为什么 + 自测**」的本地优先嵌入式面试手册。

## 我为什么写它

市面上的嵌入式八股内容库大多**停更、纯静态、无交互、无进度**，且正文常被抽走引流、无 License 不宜商用。这本手册指向一个可长期维护、可自测、可跟踪进度的版本——**先做透一批高频题，求深不求全**。

## 内容结构（三层）

每一题都是一张「题卡」，由三个层面构成：

1. **题 + 标准答案** —— 面向面试的速答要点。
2. **为什么（讲解）** —— 讲清背后的原理与推导，而非背结论。
3. **图解 / 深读** —— 正文展开更深的推导、代码与示意图。

顶层目录沿用**验证过的嵌入式命题骨架**：

- C/C++ 语言基础
- 数据结构与算法
- 操作系统与 RTOS
- Linux 基础（启动/设备树/驱动）
- ARM 体系与启动
- 总线与通信协议（I2C/SPI/UART/CAN、DMA、Flash）
- 单片机理与开发基础（GPIO、低功耗）
- 工具链与构建（编译链接、Makefile、交叉编译）
- 方法论与真题

## 如何使用

- **阅读**：左侧分类树逐题浏览，搜索框可全文检索。
- **自测刷题**：进入[自测刷题](/study)，先看题、想答案，再展开标准答案，打分「熟/生」。
- **全屏刷题**：自测页点「⛶ 全屏刷题」，单题满屏翻卡片（空格翻答案、←/→切题）。
- **记忆曲线**：`生`会进入错题本并降到 box1；连续 `熟` 依次升到 box2~5（间隔 1/3/7/15 天）。
- **进度**：全程记录在**本地浏览器 localStorage**，离线可用、无账号、无后端。
- **金句速记**：临场背诵见[面试金句速记](/guide/method/quotes)。

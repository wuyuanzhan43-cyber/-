answer: |
  **SMP（对称多处理）**：多个 CPU 核**共享内存**、**统一 OS/调度**，任务可跑到任意核；需处理**共享资源竞争、缓存一致性、调度器跨核**。
  **AMP（非对称多处理）**：各核**独立 OS/应用**、分工不同（如核A跑 Linux、核M跑 RTOS），**共享复杂**，核间靠**约定通信**；用于异构（CPU+DSP/GPU）。
  **核间通信**：
  - **共享内存 + 同步**（原子/锁/环形缓冲）。
  - **IPI（核间中断）**：一核发中断通知另一核。
  - **Mailbox/message queue**：核间消息。
  **缓存一致性（Cache Coherency）**：多核共享数据时要保证**每个核看到一致**（硬件一致性协议 MESI/类似，或软件 flush/invalidate + 原子/内存屏障）。
  **有/无一致性的区别**：SMP 有硬件一致性；异构 AMP 常无一致性，需软件同步与 barrier。
why: |
  多核提升性能，但带来**共享竞争、缓存一致性、核间通信、调度**四类问题。**SMP** 统一调度/共享内存（一致性好但竞争多），**AMP** 各核分工（异构、适合实时+通用混合，如“核A跑 Linux + 核M跑 RTOS 做主控”）。
  嵌入式异构（CPU+DSP/MCU）常用 **AMP**，靠**共享内存+IPI+mailbox**通信，并要处理**缓存一致性/内存屏障**。理解 SMP/AMP 才能做多核/异构系统。

## 深读

### SMP vs AMP

| | SMP | AMP |
|---|---|---|
| 内存 | 共享 | 各核自己（或分区共享） |
| OS | 统一（多核调度） | 各核独立 OS |
| 调度 | 跨核（任务可到任意核） | 各核自己跑 |
| 一致性 | 硬件一致性（较易） | 常需软件同步 |
| 异构 | 同构 CPU | 可异构（CPU+DSP/MCU） |
| 例 | 多核 Linux 服务器 | 手机 SoC(AP+BP)、汽车 ECU |

### 核间通信

- **共享内存**：快，但要**原子/锁/环形缓冲**同步。
- **IPI（核间中断）**：一核写标志+发 IPI 唤醒另一核。
- **Mailbox**：核间消息队列/寄存器。
- **DMA/共享 buffer**：异构间传大块数据。

### 缓存一致性

- **SMP**：硬件缓存一致性协议（如 MESI）保证多核看到一致。
- **AMP/异构**：常无一致性 → 用 **原子操作 + 内存屏障 + 显式 flush/invalidate** 保证数据一致。
- **伪共享（false sharing）**：两个核改相邻数据在同一缓存行，导致频繁失效——用**对齐/填充**避免。

### 常见追问

- SMP 和 AMP 区别？——SMP=统一 OS+共享内存+跨核调度；AMP=各核独立 OS/分工（可为异构）。
- 多核怎么通信？——共享内存+同步、IPI、mailbox。
- 异构为什么常用 AMP？——各核擅长不同（Linux 跑通用、RTOS 跑实时、DSP 跑信号），各司其职。
- 缓存一致性问题？——SMP 硬件保证；AMP 需软件同步/屏障/显式刷缓存。

> 📌 一句话记忆：**SMP=统一OS+共享内存+跨核调度；AMP=各核独立/异构分工；核间用共享内存+IPI+mailbox；SMP 硬件一致、AMP 需软件同步+屏障。**

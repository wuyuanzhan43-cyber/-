# 架构与并发进阶

> 面向「你写的跨平台嵌入式开发框架」里用到的高阶并发与架构概念。
> 这部分题库原本欠缺（原有题库偏基础八股），但**你的框架项目大量用了这些词**，面试官必然深挖：
> **无锁编程、原子操作、MPSC、内存屏障、C 语言的面向对象/设计模式、设备驱动模型、完成量、工作队列**。
> 这几个是「应届生简历上写了高级名词」的**最高危追问区**，务必读到能讲原理。

## 学习地图（按顺序读）

1. **[无锁编程 / 原子操作 / MPSC / 内存屏障](q-lockfree-mpsc)** —— 项目二「MPSC、原子操作库、零拷贝」直接支撑
2. **[C 语言的面向对象 / 设计模式 / 设备驱动模型](q-oop-in-c)** —— 简历「SOLID、设计模式、接口编程、驱动模型」直接支撑
3. **[完成量 / 工作队列 / 异步机制](q-completion-workqueue)** —— 项目二「同步原语、异步机制 workqueue」直接支撑

> 学完这三块，再回头看你项目二的架构层次（系统服务 / IPC / 同步异步脚手架 / OSAL / 驱动层 / 基础设施 / 平台层），
> 就明白每一层为什么要那么设计、还能把「八股」和「项目」闭环起来。

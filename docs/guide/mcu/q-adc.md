answer: |
  **ADC（模数转换）**把模拟电压转成数字。
  关键参数：
  - **分辨率**：位数（如 12 位 = 0~4095），决定量化精度。
  - **采样率/采样时间**：单位时间采样次数，受孔径/转换时间限制，**采样率 ≥ 2×信号最高频率**（奈奎斯特，避免混叠）。
  - **参考电压**：决定量程（如 3.3V），`value = Vin / Vref * (2^N - 1)`。
  - **通道/量程/精度/噪声**。
  **滤波/抗干扰**：
  - **均值滤波**：多次采样取平均，抑制随机噪声。
  - **中值滤波**：排序取中值，抑制脉冲/毛刺（椒盐噪声）。
  - **低通/滑动平均**（一阶滤波）：`y = a*x + (1-a)*y_prev`，平滑变化。
  - **软件去抖/多点采样**、**硬件 RC 低通**。
  原则：**噪声随机**用均值/低通；**脉冲/偶发**用中值；**变化平稳**用低通；综合可用“防抖 + 中值 + 均值”多级。
why: |
  真实信号常**叠加噪声/毛刺/抖动**，直接采样会值不稳；所以 ADC 后用**滤波**得到稳定、可信的测量值。
  理解分辨率/参考电压可算出**测量值**与**误差**；理解采样率可避免**混叠**（采样率不够→高频伪低频）。嵌入式里采集传感器（温度、电压、光强）几乎都要“采样 + 滤波”。

## 深读

### 分辨率与换算

```c
// 12 位, Vref=3.3V
uint32_t raw = adc_read();          // 0~4095
float v = (float)raw / 4095.0 * 3.3;
```

- 分辨率越高量化越细（但噪声也会被量化放大）。
- 参考电压影响精度，要稳定（可用内部基准/Vref）。

### 采样率与混叠

- **奈奎斯特**：`fs ≥ 2*fmax`，否则高频信号会被误采为低频（**混叠**）。
- 采样前可加**抗混叠低通滤波**（硬件 RC 或软件）。

### 常用滤波

| 滤波 | 公式/方式 | 适用 |
|---|---|---|
| 均值 | 多次取平均 | 随机噪声 |
| 中值 | 排序取中间 | 脉冲/毛刺 |
| 一阶低通 | `y = a*x + (1-a)*y_prev` | 平稳变化的平滑 |
| 滑动平均 | 固定窗口均值 | 平滑 |

### 滤波策略（实际）

- 先**防抖**（连续 N 次一致才算数）。
- **中值**去毛刺，再**均值/低通**平滑。
- 系数 `a` 越小越平滑但越滞后；要在“平滑 vs 响应”间权衡。

### 常见追问

- 12 位 ADC 能区分多少？——`2^12-1=4095` 级。
- 采样率不够会怎样？——混叠，高频被采成低频，读数错误。
- 噪声怎么滤？——随机→均值/低通；脉冲→中值；结合多级。
- 参考电压影响？——决定量程与精度，要稳。

> 📌 一句话记忆：**ADC=分辨率(位数)+采样率(≥2×最高频，防混叠)+参考电压(量程)；滤波再取值：随机噪声用均值/低通，毛刺用中值，先防抖。**

  **RTC 让 MCU 知道“现在几点”**，并在掉电/低功耗下**保持计时**（LSE + 备用域/备用电池）。用于**时间戳、日志、定时任务、闹钟、低功耗周期唤醒**。
  关键：**与主时钟/系统独立**（LSE 32.768kHz + 备用域），主系统复位/低功耗不影响；**闹钟/周期中断**做**按需唤醒**（配合低功耗）。是低功耗+计时场景必备。

## 深读

### RTC 组成

- **时钟源**：LSE（外部 32.768kHz，精确）或 LSI（内部 RC，精度低）。
- **预分频**：分频到 **1Hz**（秒计数）。
- **计数器/日历寄存器**：年/月/日/时/分/秒。
- **闹钟/周期**：定时/周期中断。
- **备用域**：独立供电（VBAT/电池），主掉电仍计时。

### 为什么 RTC 能掉电保持

- RTC 由 **LSE（32.768kHz）+ 备用域**供电（`VDD` 掉电时切换 `VBAT`）。
- **主时钟/主系统**断电、复位、低功耗，RTC 仍走时。
- **唤醒**：RTC 闹钟/周期中断可**唤醒**低功耗的 MCU（Stop/Standby）。

### 配置要点

```c
// 使能 RTC，选 LSE，分频到 1Hz，设时间 + 闹钟（示意）
__HAL_RCC_RTC_ENABLE();
// 配 LSE 时钟、使能 RTC、设时间、设闹钟/周期中断
```

- 时间常为 **BCD** 或需换算；注意**时区/夏令时**。
- 需要时**使能 RTC 中断**（闹钟/周期）。

### 用途与坑

- **用途**：时间戳、日志、定时记录、闹钟、低功耗周期唤醒。
- **坑**：时钟源不启（LSE 没起）、备用域没供电（掉电丢时间）、BCD/时区处理错、主时钟与 RTC 弄混（RTC 独立）。

### 常见追问

- RTC 为什么掉电还走时？——LSE + 备用域/电池独立供电。
- 时钟源用哪个？——LSE（精确）或 LSI（内部、精度低）。
- 闹钟干嘛？——定时触发/唤醒低功耗。
- 系统复位会影响 RTC 吗？——一般不影响（独立于主时钟，备用域）。

> 📌 一句话记忆：**RTC=32.768kHz 时钟源+备用域，掉电/复位仍走时（年/月/日/时/分/秒）；闹钟/周期中断作低功耗唤醒源。**

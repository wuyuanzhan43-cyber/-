  - **方向**：输入（读取电平）或 输出（驱动电平）。
  - **输入模式**：浮空/上拉/下拉/模拟；上拉/下拉决定**悬空引脚默认电平**（上拉=高，下拉=低）。
  - **输出模式**：**推挽（push-pull）**（可拉高/拉低，驱动强）或 **开漏（open-drain）**（只能拉低，需外部上拉；可“线与”，多设备共享，如 I2C）。

  - **速度/驱动能力**：翻转速率（限制信号边沿，控 EMI 与功耗）。
  - **上/下拉**：接内部或外部电阻，稳定引脚电平、定义默认状态（如按键、I2C/总线空闲态）。
why: |
  GPIO 是 MCU 与外界交互的**基础接口**，配置决定**电平行为与用途**。理解**上下拉、开漏/推挽、复用**才能正确驱动：
  - **按键**要上拉/下拉避免悬空误触发；
  - **I2C**要**开漏+外部上拉**（线与）；
  - **LED/驱动**用**推挽**；
  - **ADC/外部信号**用**输入/浮空或上下拉**。
  配置不当会导致电平不稳、短路、读不到正确值、与外设冲突。

## 深读

### 一、为什么要有上拉/下拉（从原理推导）

**浮空输入**的引脚**没有确定电平**——引脚内部既不对高也不对地，外界一点扰动（邻近电场、手指、走线耦合）就会让电压乱跳，读到的值随机、且易误触发。所以：

- **上拉**：通过电阻接到 `VCC`，默认（无输入时）为**高**；输入为低时被拉低。
- **下拉**：通过电阻接到 `GND`，默认（无输入时）为**低**。
- 目的：**给悬空引脚一个确定的默认电平**，避免浮空误读/误触发，并定义**总线空闲电平**。

内部上/下拉电阻通常较“弱”（几十 kΩ），只够**确定逻辑电平**；需要**大驱动/精确上拉**时（如 I2C、强电容负载）要用**外部电阻**。

### 二、图示：上拉/下拉电路

```
上拉(默认高)：              下拉(默认低)：
 VCC ──┤R(上拉)├──┐          GND ──┤R(下拉)├──┐
                 │ GPIO(输入)               │ GPIO(输入)
                 └── 按键(按下→接GND)        └── 按键(按下→接VCC)
 无按下=高，按下=低            无按下=低，按下=高
```

- **I2C 空闲为高**→ 用上拉；**按键默认高**（按下低）→ 上拉；**默认低**场景 → 下拉。

### 三、推挽 vs 开漏（关键区别）

| | 推挽 | 开漏 |
|---|---|---|
| 电平 | 可拉高/拉低（强驱动） | 只拉低（高需外部上拉） |
| 用途 | 单独驱动（LED/输出） | 线与/共享总线（I2C） |
| 多设备 | 不支持共享（会短路） | 支持“线与”（多设备共同拉低） |
| 典型 | LED、蜂鸣器、驱动 | I2C、开漏中断线 |

- **为什么 I2C 用开漏**：多个设备可在同一条 SCL/SDA 上**线与**（只要没人拉低就是高，有人拉低就是低），避免推挽“一个拉高一个拉低”短路。靠外部上拉提供高电平。

### 四、易错点与常见坑

- **浮空输入**：不设上下拉，读不到稳定值、易误触发。按键/总线**必须**给定默认电平。
- **方向/复用配错**：输出当输入读不到值；复用错外设不工作。
- **忘了开外设/引脚时钟**：GPIO/外设不响应。
- **推挽用于“线与”总线**：可能短路/烧（多个输出互相冲突）。
- **上下拉强度不够**：内部弱上拉带不动大负载（I2C、长线），需外部上拉。
- **翻转速度过猛**：边沿越陡 EMI/功耗越大；非必要别用超高速。

### 五、常见追问与满分回答

**Q：为什么按键要上拉/下拉？**
A：按键引脚若浮空，没有确定电平，会因干扰/悬空**误触发**。上拉（默认高）后：按键按下接 GND 拉低 → MCU 读到下降沿；确定性防误触发。（下拉同理，方向相反。）

**Q：为什么 I2C 用开漏 + 上拉？**
A：因为要**多条设备共享一条线（线与）**。开漏只能拉低，高电平由**外部上拉**提供；多个设备同时操作也能“线与”，避免推挽互相拉高拉低短路。这正是 I2C 能一总线多设备的原因之一。

**Q：上拉和下拉怎么选？**
A：看需要的**默认电平**：要默认高（如按键默认高、I2C 空闲高）用上拉；要默认低用下拉。本质是“**给悬空引脚一个确定的初始状态**”。

**Q：为什么设翻转速度？**
A：**控制边沿斜率**。太快 → 边沿陡、EMI 大、功耗高；太慢 → 可能跟不上外设/时序。非高速外设别贪快，降低 EMI 与功耗。

### ★ 深入：上拉/下拉的“强弱”与内外之分（选错会怎样）

很多人以为上/下拉开“开了就行”，其实**强度错了会出问题**。

- **内部上/下拉（弱，几十 kΩ）**：只够**确定逻辑电平**，驱动能力弱，**带不动重负载**。
- **外部上拉（强，几 kΩ）**：能带动**大电流/长线/电容负载**。

**选错会怎样**：

| 用错 | 结果 |
|---|---|
| 用**内部弱上拉**去带 I2C/长线/大电容 | 上升沿变慢（RC 大）→ **速率上不去、波形圆滑、高速通信失败**，甚至**拉不到高** |
| 上拉**阻值过小（太强）** | 电流过大/发热；且在开漏/线与时**拉低可能会被强上拉“顶住”拉不下去** |
| **方向选反** | 默认电平反了（本该默认高却默认低）→ 按键/总线初始状态错、误判 |
| **上下拉漏配**（悬空） | 电平随干扰乱跳 → 误触发/误读 |

**怎么选**：**日常逻辑电平**用内部弱上拉即可；**重负载/长线/高速（如 I2C）**用**外部上拉**并选合适阻值（I2C 常见 4.7k/10k，兼顾边沿与功耗）。**本质**：上拉/下拉既要“给确定电平”，也要“能带得动你挂的负载”。

> 📌 一句话记忆：**上拉=默认高、下拉=默认低（给悬空引脚确定电平，防误触发）；推挽强驱动（LED），开漏只拉低+外部上拉（I2C 线与、多设备共享）；弱内部只定电平、强外部才能带重负载/高速。**

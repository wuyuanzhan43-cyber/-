answer: |
  GPIO 引脚可配成**输入/输出/复用/模拟**等模式，常见参数：
  - **方向**：输入（读取电平）或 输出（驱动电平）。
  - **输入模式**：浮空/上拉/下拉/模拟；上拉/下拉决定**悬空引脚默认电平**（上拉=高，下拉=低）。
  - **输出模式**：**推挽（push-pull）**（可拉高/拉低，驱动强）或 **开漏（open-drain）**（只能拉低，需外部上拉；可“线与”，多设备共享，如 I2C）。
  - **复用（alternate）**：引脚复用成 UART/SPI/I2C/PWM/ADC 等外设功能。
  - **速度/驱动能力**：翻转速率（限制信号边沿，控 EMI 与功耗）。
  - **上/下拉**：接内部或外部电阻，稳定引脚电平、定义默认状态（如按键、I2C/总线空闲态）。
why: |
  GPIO 是 MCU 与外界交互的**基础接口**，配置决定**电平行为与用途**。理解**上下拉、开漏/推挽、复用**才能正确驱动：
  - **按键**要上拉/下拉避免悬空误触发；
  - **I2C**要**开漏+外部上拉**（线与）；
  - **LED/驱动**用**推挽**；
  - **ADC/外部信号**用**输入/浮空或上下拉**。
  配置不当会导致电平不稳、短路、读不到正确值、与外设冲突。

## 深读

### GPIO 模式速查

| 模式 | 用途 | 说明 |
|---|---|---|
| 输入（上拉/下拉/浮空） | 读取电平 | 上拉=高、下拉=低、浮空=悬空（需外部确定） |
| 输出（推挽） | 驱动 | 可拉高/拉低，驱动强 |
| 输出（开漏） | 线与/共享 | 只能拉低，需外部上拉 |
| 复用 | 外设功能 | UART/SPI/I2C/PWM/ADC… |
| 模拟 | ADC/DAC | 模拟输入 |

### 上拉/下拉的作用

- **稳定悬空引脚**：防止输入悬空时电平乱跳（干扰、误读）。
- **定义默认状态**：如按键（上拉到高，按下拉低）、总线空闲电平（I2C 上拉为高）。
- **内部 vs 外部**：内部上/下拉电阻（弱，约几十 kΩ）；大负载/精确电平需**外部电阻**。

### 推挽 vs 开漏

| | 推挽 | 开漏 |
|---|---|---|
| 电平 | 可拉高/拉低 | 只拉低（高需外部上拉） |
| 用途 | 单独驱动（LED/驱动） | 线与/共享总线（I2C） |
| 短路保护 | 注意驱动能力 | 只要外部上拉不冲突 |

- **I2C**常用**开漏 + 外部上拉**（允许线与/多设备）。
- **LED/对外输出**常用**推挽**（驱动电流强）。

### 复用与时钟

- 复用成外设前要**开对应外设时钟**（如 `RCC_APB2PeriphClockCmd` 或 `__HAL_RCC_GPIOA_CLK_ENABLE`），配置**复用功能**和**引脚**。
- GPIO 配置需与外设数据手册匹配（如复用号、上/下拉、速度）。

### 常见追问

- 为什么按键要上拉/下拉？——避免浮空误触发，给确定默认电平。
- 为什么 I2C 用开漏？——支持线与、多设备共享，电平空闲时为高（上拉）。
- 上拉和下拉怎么选？——看需要的默认电平：要默认高用上拉（按下拉低），要默认低用下拉。
- 为什么设翻转速度？——控制边沿斜率，减小 EMI/功耗；太快会增大干扰与功耗。

> 📌 一句话记忆：**GPIO 定“方向/模式/上下拉/复用”；上拉=默认高，下拉=默认低；开漏只能拉低（I2C/线与），推挽能拉高拉低（LED/驱动）。**

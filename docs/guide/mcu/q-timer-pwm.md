  **定时器（Timer）**：按**时钟分频**计数（计数器/预分频器/重装载值），可产生**定时中断/事件**，或用于**输入捕获、输出比较、PWM**。
  - **定时中断**：计数到定时值触发，用于周期性任务、心跳、延时、刻度。
  - **输入捕获（Input Capture）**：捕获输入边沿时刻，用于**测频率/脉宽/周期**（如霍尔、编码器、测速）。

  **PWM 频率** = 时钟/分频/周期；**占空比** = 比较值/周期。调节占空比即调节平均电平/功率。
why: |
  定时器是**MCU 的“时钟与波形引擎”**：给周期性事件计时、测外部信号、生成 PWM 波形。它**用硬件计数，占用的 CPU 极少**（中断/硬件自动完成），比软件 `delay` 精确、稳定。
  理解**分频/周期/占空比**就能做出**稳定时基、PWM 调速调光、频率测量、编码器测速**。常见应用：LED 呼吸灯、电机调速、舵机控制、系统 tick 时基、输入捕获测速。

## 深读

### 定时器结构（简化）

- **时钟源**（系统时钟/外设时钟）→ **预分频器（PSC）** → **计数器（CNT）** 计到**自动重装载（ARR）**则溢出/更新。
- **定时周期** = `(ARR+1) * (PSC+1) / 时钟频率`。
- 例如 72MHz，PSC=71，ARR=9999 → 定时 = `10000*72/72M = 1ms`。

### 输入捕获 vs 输出比较 vs PWM

| 功能 | 方向 | 用途 |
|---|---|---|
| 输入捕获 | 输入 | 测频率/脉宽/周期（霍尔、编码器、测速） |
| 输出比较 | 输出 | 特定计数值翻转/置位 |
| PWM | 输出 | 周期+占空比方波（调速/调光/舵机） |
| 定时中断 | 定时 | 周期任务/tick/延时 |

### PWM 参数

- **周期**：由 ARR 决定（`f = fclk/(PSC+1)/(ARR+1)`）。
- **占空比**：由比较值决定（`duty = CCRx/ARR`）。
- **调节占空比**＝调节平均输出（LED 亮度、电机平均电压、`DAC` 等效电压）。
- 常见：PWM 驱动电机（H 桥/舵机）、LED 呼吸灯、模拟输出（滤波成电压）。

### 应用要点

- **系统 tick**：用定时器做 `millis`/任务调度时基。
- **精确测量**：输入捕获测**边沿间隔**→频率/脉宽。
- **中断**：定时器中断里做**周期性处理**（但要短、可重入）。

### 常见追问

- 定时周期怎么算？——`(ARR+1)*(PSC+1)/fclk`。
- PWM 占空比怎么调？——改比较值/周期；`duty=CCR/ARR`。
- 输入捕获干嘛？——测信号频率/脉宽/周期（编码器、测速、霍尔）。
- 为什么不用软件延时？——软件延时不准、占 CPU；定时器硬件精确、异步。

> 📌 一句话记忆：**定时器=分频+计数+重装载，做定时中断/输入捕获(测频)/输出比较/PWM(周期+占空比)；硬件计时精确、少占 CPU。**

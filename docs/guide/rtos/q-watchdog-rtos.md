answer: |
  **RTOS 里看门狗的正确用法是"任务心跳汇总喂狗"，而不是单点喂。** 因为 RTOS 下系统是"**多个任务调度**"，某单个任务卡死不该让整个系统误复位，但"**关键任务卡死**"又应能被看门狗揪出来。

  **要点**：
  1. **用独立看门狗（IWDG）**：独立时钟，主时钟异常也能复位，更可靠。
  2. **喂狗点反映"系统健康"**：让**每个关键任务周期性上报"心跳/进度"**（写到一个**共享的计数/位图**），由**一个监控任务（如低优先级/Idle 任务，或专门任务）汇总后喂狗**。
     - 任何关键任务卡死/跑飞 → 心跳停 → 汇总任务**没到位** → 不喂狗 → 复位。
     - 还能**定位是哪个任务没上报**（看位图/计数）。
  3. **值班（喂狗）处**：不要在 **Idle/空闲** 或 **ISR** 里喂狗——会掩盖业务/任务卡死；要放到"确认所有关键任务都推进过"之后。
  4. **喂狗间隔 < 看门狗超时**，留足余量避免误复位。
  5. **窗口看门狗（WWDG）**：要求喂狗落入窗口内，防止"死循环空转骗过看门狗"。

  **RTOS 特有作用**：若**调度被卡住/死锁/某任务死循环**，任务心跳停 → 汇总任务跑不到 → 不喂狗 → 自动复位，相当于给 RTOS 加了一道"**调度健康**"保险。
why: |
  裸机里看门狗"喂在 main 循环"，但 RTOS 里**主循环不再是唯一主干**——真正要做的是保证**关键任务的运转**。
  - **为什么用"心跳汇总"而非单点喂**：单点喂（如任务 A 喂）只反映"任务 A 活着"，其它任务卡死它照喂，看门狗形同虚设。**每个关键任务上报心跳，汇总后喂**，才能覆盖全系统。
  - **为什么别在 Idle/ISR 喂**：Idle 任务只要调度器活着就always 能跑，业务卡死也照喂 → 掩盖故障；ISR 喂狗同理，会把"任务没跑"掩盖掉。
  - **为什么用独立看门狗**：RTOS 依赖主时钟/SysTick，若主时钟或调度崩了，用独立时钟的看门狗仍能兜底复位。
  这一题的加分点：**把"喂狗点"选成"关键任务推进点"，用任务心跳把"系统健康"量化**。

## 深读

### RTOS 看门狗架构（任务心跳汇总）

```
[任务A] 关键任务 → 每周期 写心跳位 bit A
[任务B] 关键任务 → 每周期 写心跳位 bit B
[任务C] 关键任务 → 每周期 写心跳位 bit C
        │
[监控任务(WatchDog Mon)] → 检查 位A/位B/位C 都在?
        │ 都在 → 清位 + 喂狗(IWDG)
        │ 某位没到 → 不喂 → 超时 → 复位
```

- **心跳位/计数**：每个关键任务在自己周期末尾置位/累加；监控任务**确认全部到位后再喂狗 + 清位**。
- **优点**：能**定位是哪个任务没上报**（哪个位没置），并能反映"**关键路径**"是否疏通。

### 适合/不适合喂狗的位置

| 位置 | 是否适合 | 原因 |
|---|---|---|
| 每个关键任务上报后，汇总喂 | ✅ | 反映全系统健康，能定位 |
| 在 Idle/空闲任务里喂 | ❌ | 屏蔽业务任务卡死 |
| 在 ISR 里喂 | ❌ | 屏蔽任务层卡死；ISM 无法反映调度健康 |
| 在 main 循环最前盲喂 | ❌ | 卡在某步也照样喂，掩盖故障 |
| 在窗口看门狗窗口内喂 | ✅ | 防空转（太早/太晚都复位） |

### IWDG vs WWDG（RTOS 场景）

| 类型 | 特点 | 适用 |
|---|---|---|
| 独立看门狗 IWDG | 独立时钟、可靠 | 无人值守 RTOS，强复位 |
| 窗口看门狗 WWDG | 需要窗口内喂，防空转 | 防"死循环骗狗" |
| 软件监控（wdt task） | 心跳汇总，能定位 | 多任务系统看"谁没跑" |

### 常见追问

- **Q：为什么 RTOS 不能用"单点喂狗"？**
  A：RTOS 是**多任务调度**，只喂一个点只反映"那个任务活"。真正要保护的是**关键任务的周期性推进**，所以用**心跳汇总**覆盖全系统。

- **Q：为什么不在 ISR 里喂狗？**
  A：ISR 只要不被屏蔽就几乎总能跑，**任务层卡死它照样喂**，看门狗形同虚设。喂狗应放在**任务层的关键推进点**。

- **Q：看门狗能不能救"死锁"？**
  A：能。死锁时关键任务心跳停 → 汇总任务喂不了狗 → 看门狗复位。这是 RTOS 里看门狗**兜底**死锁/卡死的一种工程手段。但**复位只是保底**，还应配合**断言/状态机/超时**尽早发现。

> 📌 一句话记忆：**RTOS 看门狗＝各关键任务上报心跳，监控任务汇总后喂狗(IWDG)&清位；喂狗点在"关键推进点"，别在 Idle/ISR 喂；间隔留余量，WWDG 防死循环；心跳汇总能定位"哪个任务卡死"。**

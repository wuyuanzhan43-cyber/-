answer: |
  **指针数组**：`int *p[10];` —— 一个数组，**每个元素都是指针**（共 10 个 `int*`）。
  **数组指针**：`int (*p)[10];` —— 一个**指针**，指向一个长度为 10 的 `int` 数组（`int[10]`）。
  区别在 `[]` 与 `*` 的**结合优先级**：`[]` 优先级高于 `*`。
  - `int *p[10]`：先结合 `[10]` → 是**数组**，元素是 `int*`。（指针数组）
  - `int (*p)[10]`：先 `(*p)` → 是**指针**，指向 `int[10]`。（数组指针）
  常用：**指针数组** = 一组指针（如字符串数组 `char* s[]`、函数指针表）；**数组指针** = 指向一整行数组（用于二维数组的行指针、`&arr` 的类型）。
  记忆：**看 `*` 和 `[]` 谁先结合（`()` 可改变结合）**；`*` 在 `[]` 外层且用括号包住 → 是指针（数组指针）；否则是数组。
why: |
  这是 C 里**最经典的“看错就写错”**的题目，考的就是**运算符优先级与类型解读**。嵌入式里常用来处理**二维数组、字符串数组、函数指针表、按行操作的缓冲**。
  常见坑：`&arr`（取整个数组地址，类型是数组指针）与 `arr`（退化成指针）的区别；二维数组 `a[i][j]` 的 `a`/`a[i]`/`&a[i][j]` 类型各不相同。

## 深读

### 两种声明的解读

```c
int *p[10];    // p 是数组，含 10 个 int*  → 指针数组
int (*q)[10];  // q 是指针，指向 int[10]   → 数组指针
```

- `[]` 优先级高于 `*`，所以 `int *p[10]` 先结合 `[10]`（数组），元素是 `int*`。
- `(*q)` 用括号改变结合，`q` 先是指针，再指向 `int[10]`。

### 常见用法

```c
// 指针数组：字符串数组
char *names[] = {"alice","bob","carol"};

// 数组指针：二维数组的行指针
int a[3][4];
int (*row)[4] = a;   // row 指向一行(4个int)；a[0] 是 int*, a 是 int(*)[4]
```

- `a`（二维数组名）类型是 `int(*)[4]`（数组指针），`a[i]` 是 `int*`（行首）。
- `&a` 类型是 `int(*)[3][4]`。

### 常见追问

- `char **p` 是什么？——指针的指针（指向 `char*`），常用于字符串数组/参数传递。
- `a` 和 `&a` 类型一样吗？——不同：`a`（数组名）退化为指针（`int(*)[4]`），`&a` 是指向整个数组的指针（`int(*)[3][4]`），数值相同但步长不同。
- 为什么用函数指针数组？——做命令分发/跳转表。

> 📌 一句话记忆：**`int *p[10]`=指针数组（元素是指针）；`int (*p)[10]`=数组指针（指向数组）；看 `[]` 与 `*` 谁先结合。**
